# Question Poker

Question Poker is a 2D card game built with Unity. It combines poker-inspired card play, dialogue-driven progression, items, betting mechanics, and animated visual effects.

## Requirements

- Unity `2022.3.58f1c1`
- Git LFS (required for video and audio assets)

## Getting started

1. Install [Git LFS](https://git-lfs.com/) and run `git lfs install`.
2. Clone this repository.
3. Open the repository folder in Unity Hub with Unity `2022.3.58f1c1`.
4. Open `Assets/Scenes/Login.unity` to start from the first scene.

## Large local assets

GitHub's per-file size limit prevents the repository from including the three cinematic videos under `Assets/Resources/Video` and the generated `Assets/Fonts/games/MSYH SDF.asset` font atlas. These files remain in the original local Unity project and can be regenerated or copied into a local checkout when needed.
